# IMPOSTOR

Мобильная игра «Импостор» на React + TypeScript. Есть локальный pass-and-play режим и основа online-режима через Supabase Realtime.

## Запуск

```bash
npm install
npm run dev
```

Локальный режим работает без внешних сервисов.

## Online через Supabase

1. Создайте проект Supabase.
2. Выполните SQL из `supabase/migrations/001_initial.sql` в SQL Editor.
3. Скопируйте `.env.example` в `.env`.
4. Укажите `VITE_SUPABASE_URL` и `VITE_SUPABASE_PUBLISHABLE_KEY`.
5. Запустите `npm run dev`.

Секреты раунда не доступны через публичные таблицы. Клиент получает собственную роль через `get_my_secret`.

## GitHub Pages

Workflow находится в `.github/workflows/deploy.yml`. В репозитории добавьте Actions secrets `VITE_SUPABASE_URL` и `VITE_SUPABASE_PUBLISHABLE_KEY`, затем включите Pages с источником GitHub Actions.

## Проверки

```bash
npm test
npm run build
```

## Изменения UX локальной игры

- Секретная карточка полностью закрывает роль, слово и подсказку до удержания кнопки.
- Категория никогда не показывается Импостору.
- В локальной игре нет передачи телефона для индивидуального голосования: группа выбирает подозреваемого на одном экране.
- Добавлен режим «Обычный режим» с общеизвестным пулом слов.
- Добавлен экран правил и дополнительные игровые подсказки.
- Миграции `003_common_words.sql`–`005_word_mode_filter.sql` расширяют словарь, закрывают категорию Импостору и применяют фильтр режима слов в online-раундах.

## Миграции 006–007

После предыдущих миграций примените `006_online_game_flow.sql`, затем `007_better_hints.sql`.

`006` добавляет полный online flow после раздачи ролей: автоматический переход к игре после просмотра карточек, TEXT/VOICE режимы, очередь текстовых ассоциаций, переход Host к голосованию в голосовом режиме, приватные голоса и результат раунда.

`007` начинает замену старых категорийных подсказок на персональные наборы по 3 подсказки для конкретных слов. Новые слова следует добавлять только с персональными подсказками.
